# NESA-Africa Data Platform
# Evidence Grades

## Purpose

Evidence grades are used to record the strength of evidence supporting
information about an education programme or partnership.

The evidence classification used by this project is:

- A
- B
- C

Evidence status must be kept separate from whether a reported figure
represents an actual achieved result or a target.

---

## Grade A — Strong Evidence

Grade A represents strong primary evidence supported by measurable
results or outcomes.

Examples of supporting evidence may include:

- Official programme documentation
- Official monitoring or evaluation results
- Measurable achieved outcomes
- Official reports containing results
- Primary evidence from the implementing organisation

### Data value

```text
evidence_grade = A
